# PHP LAB 💻

### Laboratorio de programación del lado del servidor

PHP LAB es un proyecto académico desarrollado para aprender y practicar los fundamentos del lenguaje PHP mediante ejemplos prácticos, dinámicos e interactivos.

El proyecto está organizado por módulos que permiten comprender los principales conceptos de programación del lado del servidor.

---

## 🎯 Objetivo del proyecto

Desarrollar un laboratorio web que permita estudiar y ejecutar ejemplos de PHP, comprendiendo el funcionamiento de variables, estructuras de control, ciclos, arreglos y manejo de sesiones.

## 🛠️ Tecnologías utilizadas

- **PHP:** Lenguaje de programación del lado del servidor.
- **HTML5:** Estructura de las páginas web.
- **CSS3:** Diseño y estilos visuales.
- **Apache:** Servidor web local.
- **XAMPP:** Entorno de desarrollo local.
- **Visual Studio Code:** Editor de código.
- **Git y GitHub:** Control de versiones y almacenamiento del proyecto.

## ⚙️ Instalación y ejecución

Para ejecutar PHP LAB localmente se necesita:

- Windows 10 o compatible.
- XAMPP instalado.
- Visual Studio Code.
- Navegador web.

### Paso 1. Instalar XAMPP

Descargar XAMPP desde:

https://www.apachefriends.org/

### Paso 2. Copiar el proyecto

Colocar la carpeta PHP-LAB dentro de:

```text
C:\xampp\htdocs\
```

### Paso 3. Iniciar Apache

1. Abrir XAMPP Control Panel.
2. Iniciar el módulo Apache.
3. Comprobar que Apache esté activo.

### Paso 4. Abrir el proyecto

Ingresar desde el navegador a:

```text
http://localhost/PHP-LAB/
```

¡Listo! El laboratorio estará disponible en el navegador.
